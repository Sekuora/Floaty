### About

![Cover Image Floaty](https://github.com/Sekuora/Floaty/blob/65949731f555d77b21de1526daa6a0f2a5d182f4/LogoImage_floaty.png)

Floaty is a tool to open your blender editors into new windows and reorganize your workspace.

Designed for simplicity and usability floaty brings unique time saving features to your workflow.

With floaty you can create the workspace you need exactly how you need it.
---

### How to use
When you install floaty you will see a new button in your headers.

*Click* the float button to detach the editor.

Once detached :
*Click* it again to attach in the position you want.

*Hold shift + click* to move the editor space without detaching it.

The positions to place the editor are:

- Far Left - To the left of all editors.

- Far Right - To the right of all editors.

- Above All - Above all editors.

- Below All - Below all editors.

And per each editor in your workspace you have options to attach a window:

- Below - Below the select editor.

- Above - Above the selected editor.

- Left - To the left of the selected editor.

- Right - To the right of the selected editor.


### Sidebar

3d-View->sidebar->floaty

- Select in which editors you want to see the float button.

Active Editor.

- Float button.

Detached Windows

- Track the currently detached windows.
